StudyMindAI

The study assistant that reads your own notes, explains them at your level, and turns them into quizzes, flashcards and a plan.

Explore features → Meet the creator

What it is

One assistant. Your own material. Real practice.

StudyMind AI runs on Android phones and Windows computers. Upload your PDFs, TXT and DOCX notes, ask questions grounded in them, then practise with quizzes and flashcards that come from the same material.

Upload

Drop in PDF, TXT or DOCX notes. Text is extracted and organised into folders.

Ask

Get explanations at your level, summaries, and answers that cite the page they came from.

Practise

Generate quizzes and flashcards straight from the notes you picked.

Plan and track

Schedule sessions, run a focus timer, and see progress built from real stored events.

FLASH

Rate a card Again, Hard, Good or Easy. I handle when it comes back.

Architecture

Clients, a protected API, and two data stores.

A website is not a Windows app

Two deliberate ways to ship.

Android ships from Expo's build service as an APK or AAB. Windows is a separate packaging step: the web build is wrapped in a desktop shell such as Electron or Tauri and bundled into an installer. Nothing about the Windows version happens by accident.

SENTRY

Text inside an uploaded file is untrusted input. Nothing in a document gets to override the app's rules.

Security model

Twelve rules the backend enforces.

Honest note

StudyMind AI is not claimed to be breach-proof. No app is. Remaining risks are documented, and production security checks are required before launch.

        Packaging

        Getting installable apps out of one codebase.

        Android

        Develop with Expo, then build in the cloud for an APK or AAB.

        npx create-expo-app studymind
npx expo start      # Expo Go or an emulator
npm i -g eas-cli
eas build -p android # APK or AAB

        Windows

        Export the web build, wrap it in a desktop shell, bundle an installer.

        npx expo export -p web   # static web build
# wrap dist/ in Electron or Tauri
npx electron-builder --win # installer

        Indicative commands. Exact flags depend on the project's configuration.
